# Contexte

## Sujet

Outil de structuration de projet par agents Claude interconnectés. Un agent chat récolte le besoin du client, un agent principal distribue les tâches, et des agents spécialisés produisent l'architecture, la stack, la documentation et un prototype frontend. Trois points de validation humaine encadrent le processus.

- [ ] Coder les agents
- [ ] Mettre en place les checkpoints de validation
- [ ] Lancer le test Haiku contre Sonnet sur les lignes `a_tester`

## Stack technique

- Modèles Claude : Opus 5.5, Sonnet 5.5, Haiku 5.5
- Orchestration : à confirmer (Claude Agent SDK envisagé)
- Frontend : HTML/CSS vanilla
- Versionnement : Git
- Configuration : Markdown et YAML

## Attendus

- Un outil propre, utilisable à chaque nouveau projet
- Trois checkpoints de validation par Noham
- Un livrable : un repo Git prêt à coder et un prototype HTML
